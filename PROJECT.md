# Rocket Hunter: паспорт проекта

## Что это
Бот для Bybit Demo Trading (не testnet), линейные USDT-перпетуалы, Windows, Python, папка D:\rocket_hunter, запуск через start_bot.bat.
Идея: ловит импульс цены вверх (лонг) и вниз (шорт), держит прибыль трейлинг-стопом.

## Файлы
- main.py: главный цикл, Telegram, проверка списка монет при старте
- start_bot.bat: запуск с автоперезапуском
- config.py: все настройки (пороги, стоп, трейлинг, лимиты)
- core/strategy.py: сигналы входа, досрочный выход при развороте, сверка позиций, лог сделок
- core/orderbook.py: метрики (скорость ленты, дельта, имбаланс стакана)
- core/ws_manager.py: рыночные данные с Bybit (3 эшелона монет), запись parquet
- execution/order_manager.py: ордера, SL/TP, трейлинг-стоп, закрытие позиции

## Принятые решения
- Плечо 2x, размер позиции $40 и для лонга, и для шорта
- Отдельные пороги входа: PUMP_* для лонга, DUMP_* для шорта (не зеркальные)
- Шорты разрешены на всех 25 монетах списка
- Жёсткий SL 1%, TP 5%, трейлинг включается при +1.5%, дистанция 0.8% (доли от цены входа)
- Досрочный выход при развороте сигнала (REVERSAL_*), первые 10 секунд не проверяется
- Дневной лимит убытков 50 USDT блокирует только новые входы, выход из позиций работает всегда
- Токен Telegram и ключи Bybit только в переменных окружения, в коде их нет

## Сделано
- Вход лонг/шорт, SL/TP, трейлинг на стороне биржи
- Досрочный выход при развороте
- Лог сделок: D:\rocket_hunter_data\trades_log.csv
- Подхват открытых позиций после перезапуска, дневной PnL после перезапуска
- Проверка названий монет при старте (лишние исключаются с предупреждением в логе)
